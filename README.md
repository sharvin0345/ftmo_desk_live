# FTMO Desk Live

Public, read-only dashboard for a **FTMO $10,000 2-step Phase 1 DEMO** trading desk.

- Live site: https://sharvin0345.github.io/ftmo_desk_live/
- This repository holds only the static page and a sanitized `data.json` (balances, P&amp;L, positions, trade history, schedule).
- Account credentials, the MT5 login, server name, and passwords are never published here.
- `data.json` is updated automatically by the desk after trades are recorded, placed, cancelled, or journaled, and only when those numbers change.
- The page auto-refreshes every 60 seconds.

This is a demo account. It is not financial advice and not an FTMO-affiliated product.
